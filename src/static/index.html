Failure Inspection: Why Dense Search Failed

Every miss (Q01, Q02, Q03, Q04, Q09) was verified to exist in the corpus chunks. Dense vector embeddings fail because natural language questions about exact alphanumeric error codes (51 - Decline, 14, 430357) match generic prose troubleshooting overviews in cosine space rather than the precise table rows. This provided the empirical justification for introducing BM25 + RRF Hybrid Search in Week 4.

Reciprocal Rank Fusion Formula

$$RRF(d) = \sum_{m \in \{dense, bm25\}} \frac{1}{60 + rank_m(d)}$$ By setting the smoothing constant $k=60$, RRF ensures that candidate chunks ranking highly in BM25 keyword search (such as error table rows with exact code strings) receive significant ranking boosts, compensating for low dense semantic similarity scores.
